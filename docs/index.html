What it does

Nine detectors. One score. Zero guessing.

Agent / MCP interface

AI coding agents query real debt data directly over a local MCP server — no more grepping for TODOs.

Complexity analysis

Cyclomatic complexity, long methods, God classes, and deep nesting — flagged before they metastasize.

N+1 query detection

Flags Eloquent lazy-load patterns inside loops and collection iterators, before they hit production.

Security smell detection

eval/exec, hardcoded credentials, unsafe unserialize, SQL concatenation, and debug leakage.

Git-aware scoring

Older debt scores higher — age is the multiplier, straight from git blame.

Laravel Pulse dashboard

Grade, score trend, and the git-author leaderboard — visible on your team's dashboard, zero extra packages.

How scoring works

Not a linter. A grade you can act on.

Grade thresholds

Total score across every detector, mapped to a letter.

A0–100
B101–300
C301–600
D601–1000
F1001+

Age multiplier

Older debt scores higher — the same issue, untouched for 6 months, weighs 3× more.

1.0×fresh · <30d
1.5×growing · 30–89d
2.0×chronic · 90–179d
3.0×critical · 180d+
For your pipeline

Block a PR before the debt ships

Two opt-in flags on debt:scan and debt:summary turn a report into a merge gate. Set them once in config, or override per workflow — a CLI flag always wins.

--fail-on-grade=Cfails when the grade is C or worse
--max-score=500fails when the total score exceeds 500

Exit codes: 0 passed · 1 breached · 2 invalid flag.

.github/workflows/tests.yml 
- name: Technical debt gate
  run: php artisan debt:scan --fail-on-grade=C
Get started

Install
